# 第 2 部分 — 快速入门指南

> **"我是新用户，该怎么办？"**
> 这一页指南让全新的员工第一天就能上手。你不需要任何会计或软件背景。
> 只需跟着十步走。

## 你要学的 10 件事

### 1. 登录
在浏览器中打开系统。在**登录页**输入工作邮箱和密码（由管理员提供）。
如果你的密码是管理员设置的，首次登录时会被要求**修改密码**。如果你的角色
要求，还需要用身份验证器应用设置**两步验证（2FA）**（见第 9 部分）。
- 从登录界面或顶部工具栏的 🌐 选择器选择语言（English / ខ្មែរ Khmer / 中文 Chinese）。

### 2. 看看仪表板
登录后会进入**仪表板**。它一眼回答早上的问题：物业住得多满、本月计了
多少和收了多少、还欠多少（**欠款**）、手头现金、未结维修工单，以及一张
**Rent dues（租金到期）** 卡片，显示即将到期和已逾期的款项。
👉 *试一试：* 用 `staff@demo.test` 登录，把每张卡片读一遍。

### 3. 理解菜单
左侧边栏按工作分组：
- **Overview** → 仪表板
- **Portfolio** → 物业、会员、业主、租约
- **Billing** → 租金引擎、账单、收款、押金、水电费、服务
- **Finance** → 账本、支出与损益、业主对账单
- **Operations** → 换房、检查、维修、投诉、短租、考勤
- **Store** → 收银台、收银商品目录、库存、采购单
- **Comms** → 租客门户、Telegram 机器人
- **Insights** → 报表
- **Admin** → 用户、角色、审计日志、设置、安全 *（仅管理员）*

如果看不到某个菜单项，说明你的角色没有相应权限 — 这是正常的，也是设计如此。

### 4. 跟随引导参观
点击顶部工具栏的 **Help (?)** 按钮，播放一段脚本化的界面高亮参观。每个模块
在帮助对话框里还有一条"用途 + 技巧"的简短说明。

### 5. 记住唯一的黄金法则
**已入账的钱永不删除。** 你用正确的冲销工具纠正错误（账单用红字通知单、
费用用冲销、收食用退款）。绝不要试图通过编辑来"修"已入账的数字 — 系统
不让你这么做，这也保护了所有人。

### 6. 学会状态词
- **房间：** vacant → reserved → occupied → cleaning → maintenance → vacant。
- **会员：** prospect → verified → active → notice → moved_out。
- **租约：** draft → active → notice → terminated/completed。
- **账单：** draft → issued → partial_paid → paid → overdue（或 void）。
- **收款：** pending → confirmed（或 failed / refunded）。

### 7. 做核心每日循环
工作的核心：**看仪表板 → 看租金到期 → 收款/记录收款 → 出具收据 →
提出或更新工单。** 大多数日子就是这个循环。

### 8. 了解账单是怎么生成的
租金**不是**每月手工录入的。系统从每个生效租约生成账单（租金 + 服务 + 水电）。
有权限的人触发**账单生成**（或由定时任务完成）。然后你按这些账单收款。
（细节见第 3 部分和第 5 部分。）

### 9. 知道你能做什么
你的角色决定一切。如果按钮不存在，或者你收到 **403 FORBIDDEN**，说明
你没有该权限 — 问你的经理，不要绕过。

### 10. 知道去哪里求助
- 应用内：**Help (?)** 参观和模块提示。
- 本手册：常见问题见**第 10 部分（故障排除）**和**第 11 部分（FAQ）**。
- 访问问题：联系管理员（第 8 部分）。
- 金额差异：联系会计 / 管理员，并使用**审计日志**。

## 30 秒心智模型

```
一间房通过租约容纳一位会员。
租约每月生成账单。
账单被支付；收款产生收据和账本分录。
成本是费用。收入 − 成本 = 利润（P&L）。
业主得到月度对账单和分成。
```

## 每日 / 每周 / 每月节奏

| 何时 | 做什么 |
|---|---|
| **每日** | 查看仪表板与租金到期；记录收款并出具收据；处理 POS 销售；处理新工单/投诉；打卡（考勤） |
| **每周** | 追缴逾期账单（催缴）；跟进未结维修；查看低库存告警；完成到期检查 |
| **每月** | 录入水电表读数；运行账单生成；核对收款；记录费用；查看损益；生成业主对账单；运行报表 |

> ✅ 当你能大声说清楚租约如何变成账单、账单如何变成收款、收款如何
> 出现在损益表上 — 你就懂了这套系统。这个流程画在**第 1 部分 §1.4**，
> 并在**第 13 部分（黄金路径）**中分步教授。
