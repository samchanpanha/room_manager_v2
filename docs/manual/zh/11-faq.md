# 第 11 部分 — 常见问题（FAQ）

用日常语言写。多部分问题用"**问** / **答**"。

**登录**
- **问：怎么登录？** 在登录页输入工作邮箱和密码。Admin 账户还要输 2FA 码。新设的管理员密码首次登录必须改。
- **问：忘了密码 — 有重置邮件吗？** 当前系统没有（没有邮件通道）。请管理员设一个临时密码；下次登录时你会改掉它。
- **问：为什么看不到某个菜单项？** 你的角色没有它的权限（或功能开关关了）。这是设计如此 — 需要就找管理员。
- **问：总是收到 "403 FORBIDDEN"。** 你缺少模块/操作权限，或没被分配到该物业。申请访问权；别尝试绕过。
- **问：会员怎么登录租户门户？** 用发到其 email/手机的一次性密码（OTP）。码一次性，5 次后锁定。

**物业、会员、租约**
- **问：怎么创建租约？** 先确保 物业→楼宇→楼层→房间 存在，且会员已完成 KYC 验证。然后 **Leases → New**，选会员 + 房间，设租金/开始日/押金/服务，存草稿，然后 **Activate**（第 3.6 节）。
- **问：一个房间能有两名租户吗？** 最多到床位容量。**每床位一个生效租约**；系统拦截超订。
- **问：怎么改月租金？** 不编辑已出账账单。租金条款在租约上快照；将来变更用续租/换房/新租约条款。设置变更**只向前**生效。
- **问：房间颜色/状态是什么意思？** vacant 空闲、reserved 预留（草稿租约）、occupied 已住（生效租约）、cleaning 清洁中（退房后）、maintenance 维修中（需修理）。
- **问：怎么取消/结束合同？** 发出通知、清未结欠款（或经审批核销）、完成退房检查，然后 terminate/complete。房间进 cleaning，押金结算。
- **问：怎么把租户拉黑？** 从会员档案，原因必填；它阻断状态流转和新租约。解除拉黑也留审计。

**计费与钱**
- **问：月度账单怎么产生？** 不用手输。运行**账单生成**（或计划任务）：租金 + 服务 + 水电 + 一次性 − 折扣 + 税。它幂等且编号无缺口。
- **问：能加多个服务吗？** 能 — WiFi、停车、洗衣等。固定月费服务每月计费（月中开始/停止则折算）；按次成为一次性行。
- **问：怎么记部分收款？** 直接输实收金额。它按旧到新分摊，账单变 **partial_paid**；剩余仍应付。
- **问：租户付了为什么还有未结余额？** 收款可能 **pending**（QR 未确认）、记在错会员上，或是部分收款。查收款状态和分摊。
- **问：租户付多了会怎样？** 多出的钱留作 **member credit**（不是收入），会计可退。
- **问：能改/删旧收款/账单吗？** 不能删除。账单用 **credit note** 更正（或 Super Admin 带原因 void）；收款用 **refund** 冲销（会计审批）。
- **问：滞纳金和提醒怎么运作？** 宽限期（默认 3 天）后，每日任务加滞纳金并标记逾期；催收提醒在 +3/+7/+14 天。
- **问：押金是我的收入吗？** 不是 — 是保管款（负债）。退房时退款或扣款（带凭证）。
- **问：怎么看账本？** 打开 **Finance → Ledger**：日记账（按时间排列的分录）和试算平衡。每笔分录借方 = 贷方（第 5 部分）。
- **问：怎么看利润？** **Profit & Loss** 报表（或 Expenses & P&L）：收入 − 费用 − 业主分成 = 净利。

**报表**
- **问：谁能看财务报表？** 报表需要 M26。财务/管理员看财务报表；物业经理看自己物业的运营报表；业主看自己的对账单历史。
- **问：有资产负债表吗？** 没有专门的资产负债表界面；用 **Ledger → Trial balance**（资产 1100–1300、负债 2100–2300、权益 3900）。见第 5.6 节。
- **问：怎么导出报表？** 用每张报表上的 **CSV** 或 **PDF** 导出按钮（按日期 + 物业筛选）。

**通知 / Telegram**
- **问：怎么连接 Telegram？** 在应用/门户拿一次性码，向 bot 发消息 `/link <code>`，然后开你的通知开关（第 7.2 节）。
- **问：会收到邮件收据吗？** 当前版本不会 — 自动化消息走 Telegram；应用内徽章/仪表板也显示欠款。
- **问：会员在 bot 里能做什么？** `/status`（其租约）、`/dues`（余额）、`/pay`（拿支付 QR）、`/help`。他们永远只看自己的数据。

**管理员**
- **问：怎么加新用户？** Admin → Users → New user（email + 临时密码，首次登录强制修改），然后分配角色和物业（第 8.2 节）。
- **问：怎么改权限？** Admin → Roles & Permissions → 勾选 模块 × 操作 × 范围 网格。变更留审计；别给超出需要的（第 8.3 节）。
- **问：能删 Super Admin 角色吗？** 不能 — 它受保护，确保始终有全权限账户。使用中的角色不能删。
- **问：怎么关掉一个模块？** Settings → Features（功能开关）。它隐藏模块/门控访问，不删数据。
- **问：在哪里设货币 / 滞纳金 / 催收？** Settings → Locale（货币）和 Settings → Billing / Late fee。这些只向前生效。
