# ផ្នែក ២ — ក្រមចាប់ផ្ដើមរហ័ស

> **"ខ្ញុំជាអ្នកប្រើថ្មី។ ខ្ញុំគួរធ្វើអ្វី?"**
> ក្រមទំព័រតែមួយនេះ ធ្វើឱ្យបុគ្គលិកថ្មីៗអាចប្រើប្រាស់បានតាំងពីថ្ងៃដំបូង។ អ្នកមិន
> ចាំបាច់មានបទពិសោធន៍គណនេយ្យ ឬកម្មវិធីទេ។ គ្រាន់តែអនុវត្តតាមជំហានទាំង ១០។

## ទំព័រ ០ ដំបូងដែលអ្នកត្រូវរៀន

### 1. ចូលប្រើ
បើកប្រពន្ធនៅក្នុង browser។ នៅ**ទំព័រចូល** បញ្ចូលអ៊ីមែលធ្វើការ និង
ពាក្យសម្ងាត់របស់អ្នក (អ្នកគ្រប់គរងផ្ដល់ពួកវា)។ ប្រសិនបើពាក្យសម្ងាត់របស់អ្នក
ត្រូវបានកំណត់ដោយ admin អ្នកនឹងត្រូវបានស្នើឱ្យ**ផ្លាស់ប្ដូរវានៅពេលចូលដំបូង**។
ប្រសិនបើតួនាទីរបស់អ្នកតម្រូវ អ្នកក៏ត្រូវកំណត់**ការស្គាល់អត្តសញញាណពីរជាន់ (2FA)**
ជាមួយកម្មវិធី authenticator ផង (មើលផ្នែក 9)។
- ជ្រើសភាសារបស់អ្នក (English / ខ្មែរ Khmer / 中文 Chinese) ពី 🌐 picker នៅ
  អេក្រង់ចូល ឬរបារលើ។

### 2. មើលផ្ទាំងគ្រប់គរង
បន្ទាប់ពីចូល អ្នកនឹងឈានដល់**ផ្ទាំងគ្រប់គ្រង**។ វាឆ្លើយសំណួរព្រឹកនោះ
ក្នុងពេលបែបទេ៖ អចលនទ្រព្យពេញប៉ុន្មាន, ខែនេះបានគណនា និងប្រមូលប្រាក់ប៉ុន្មាន,
ប៉ុន្មានដែលនៅត្រូវបង់ (**arrears**), ប្រាក់សាច់ក្នុងដៃ, សំបុត្រជួសជុលដែលនៅបើក,
និងកាត **Rent dues** ដែលបង្ហាញអ្វីដែលជិតមកដល់ និងអ្វីដែលផុតកំណត់។
👉 *ព្យាយាមមើល៖* ចូលជា `staff@demo.test` ហើយអានកាត foreach ចេញច្បាស់។

### 3. យល់ពីម៉ឺនុយ
របាររួមខាងឆ្វេង រៀបចំការងារ៖
- **Overview** → ផ្ទាំងគ្រប់គ្រង
- **Portfolio** → អចលនទ្រព្យ, សមាជិក, ម្ចាស់, កិច្ចសន្យាជួល
- **Billing** → ម៉ាស៊ីនថ្លៃជួល, វិក្កយបត្រ, ការទូទាត់, ប្រាក់កក់, ទឹកអគ្គិសនី, សេវាកម្ម
- **Finance** → បញ្ជីគណនេយ្យ, ចំណាយ និង P&L, របាយការណ៍ម្ចាស់
- **Operations** → ការផ្លាស់បន្ទប់, ការត្រួតពិនិត្យ, ការជួសជុល, ការតវ៉ា, ការស្នាក់ខ្លី, ការវត្តមាន
- **Store** → POS, កាតាឡុក POS, ស្តុក, លិខិតបញ្ជាទិញ
- **Comms** → ខ្លោងទ្វារអ្នកជួល, តេលេក្រាមបូត
- **Insights** → របាយការណ៍
- **Admin** → អ្នកប្រើ, តួនាទី, កំណត់ត្រាតរួតពិនិតយ, ការកំណត់, សុវត្ថិភាព *(admin តែប៉ុណ្ណោះ)*

ប្រសិនបើអ្នកមើលមិនឃើញចំណុចម៉ឺនុយណាមួយ តួនាទីរបស់អ្នកគ្មានសិទ្ធិសម្រាប់វា — នោះ
ជាធម្តា ហើយតាមការរចនា។

### 4. តាមដានដំណើរឧត្ដមនិក
ចុចគ្រាប់បូតុង **Help (?)** នៅរបារលើ ដើម្បីដំណើរការដំណើររំលឹកតាមបន្ទាត់
នៃអេក្រង់។ ម៉ូឌូល foreach ក៏មានកំណត់សម្គាល់ខ្លី "អ្វីដែលវាធ្វើ + គន្លឹះ" នៅ
ប្រយុទ្ធមជឈទណ្ឌជំនួយដែរ។

### 5. រៀនក្បួនមាសមួយ
**ប្រាក់ដែលបានចុះបញ្ជី មិនត្រូវបានលុបទេ។** អ្នកកែបកំហុសដោយឧបករណ៍រំលំ
ត្រឹមត្រូវ (credit note សម្រាប់វិក្កយបត្រ, void សម្រាប់ចំណាយ, refund សម្រាប់
ការទូទាត់)។ កុំព្យាយាម "កែ" លេខដែលបានចុះ ដោយកែវាផ្ទាល់ — ប្រព័ន្ធតម្ា
បាងអ្នក ហើយវារក្សាសនិបាតគ្រប់គ្នា។

### 6. រៀនពាក្យសថានភាព
- **បន្ទប់** vacant → reserved → occupied → cleaning → maintenance → vacant។
- **សមាជិក៖** prospect → verified → active → notice → moved_out។
- **កិច្ចសន្យាជួល៖** draft → active → notice → terminated/completed។
- **វិក្កយបត្រ៖** draft → issued → partial_paid → paid → overdue (ឬ void)។
- **ការទូទាត់៖** pending → confirmed (ឬ failed / refunded)។

### 7. ធ្វើវដ្ដប្រចាំថ្ងៃស្នូល
បេះដូងនៃការងារ៖ **ពិនិត្យផ្ាំងគ្រប់គ្រង → មើលបណ្ណ់ជួល → ប្រមូល/ចុះ
ការទូទាត់ → ចេញប័ណ្ទូទាត់ → បងើប ឬធ្វើទំនើបកម្មសំបុត្រ។** ថ្ងៃភាគច្រើន
ជាវដ្ដនេះ។

### 8. រៀនពីរបៀបការគណនាប្រាក់កើតឡើង
ថ្លៃជួល **មិន** ត្រូវបានវាយដៃរាល់ខែទេ។ ប្រព័ន្ធបង្កើតវិក្កយបត្រពី
កិច្ចសន្យាជួលសកម្ម foreach (ថ្លៃជួល + សេវា + ទឹកអគ្គិសនី)។ មនុស្សមានសិទ្ធិ
បណ្ដេញ**ការបង្កើតវិក្កយបត្រ** (ឬការងារកំណត់អូតូម៉ាទិកធ្វើវា)។ បន្ទាប់មក
អ្នកប្រមូលប្រឆាំងវិក្កយបត្រទាំងនោះ។ (លម្អិតនៅផ្នែក 3 និង 5)។

### 9. ដឹងពីអ្វីដែលអ្នកមានសិទ្ធិធ្វើ
តួនាទីរបស់អ្នក ជាអ្នកសម្រេច។ ប្រសិនបើគ្រាប់បូតុងមិនមាន ឬអ្កទទួលបាន
សារ **403 FORBIDDEN** អ្នកគ្មានសិទ្ធិនោះ — សួរអ្នកគ្រប់គ្រងរបស់អ្នក កុំព្យាយាម
ដោះស្រាយវាដោយខ្លួនឯង។

### 10. ដឹងពីកន្លែងដែលទទួលជំនួយ
- ក្នុងកម្មវិធី៖ ដំណើរ **Help (?)** និងគន្លឹះម៉ូឌូល។
- ក្រមនេះ៖ **ផនែក 10 (ការដោះស្រាយបញ្ហា)** និង **ផ្នែក 11 (FAQ)** សម្រាប់បញ្ហាជួញជុំ។
- បញ្ហាចូលប្រើ៖ ទំនាក់ទំនងអ្នកគ្រប់គរង (ផ្នែក 8)។
- ភាពខុសគ្នាប្រាក់៖ ទំនាក់ទំនងគណនី / Admin ហើយប្រើ **កំណត់ត្រាតរួតពិនិតយ**។

## គំនិត ៣០ វិនាទី

```
បន្ទប់មួយ ផ្ទុកសមាជិកមួយ តាមរយៈកិច្ចសន្យាជួល។
កិច្ចសន្យាជួលបង្កើតវិក្កយបត្ររាល់ខែ។
វិក្កយបត្រតរូវបានបង់; ការទូទាត់បង្កើតប័ណ្ណ និងចំណុចបញ្ជី។
ថ្លៃដើមជាចំណាយ។ ចំណូល − ថ្លៃដើម = ចំណេញ (P&L)។
ម្ចាស់ទទួលរបាយការណ៍ និងប្រាក់បង់ប្រចាំខែ។
```

## វដ្តប្រចាំថ្ងៃ / ប្រចាំសប្ដាហ៍ / ប្រចាំខែ

| ពេល | អ្វីដែលអ្នកធ្វើ |
|---|---|
| **ប្រចាំថ្ងៃ** | ពិនិត្យផទាំងគ្រប់គ្រង និងបណ្ណ់ជួល។ ចុះការទូទាត់ និងចេញប័ណ្ទូទាត់។ ដំណើរការការលក់ POS។ ដោះស្រាយសំបុត្រ/ការតវ៉ាថ្មី។ ចុះ/ឡើងវេន (ការវត្តមាន) |
| **ប្រចាំសប្ដាហ** | តាមដានវិក្កយបត្រផុតកំណត់ (ការហៅបង់)។ តាមដានការជួសជុលដែលបើក។ ពិនិត្យការព្យាបាលស្តុកទាប។ បញ្ចប់ការត្រួតពិនិត្យដែលដល់កាល |
| **ប្រចាំខែ** | បញ្ចូលការអានម៉ែត្រទឹកអគ្គិសនី។ ដំណើរការការបង្កើតវិក្កយបត្រ។ សមកាលការទូទាត់។ ចុះចំណាយ។ ពិនិត្យ P&L។ បង្កើតរបាយការណ៍ម្ចាស់។ ដំណើរការរបាយការណ៍ |

> ✅ នៅពេលអ្នកអាចពិពណ៌នាចេញច្បាស់ពីរបៀបដែលកិច្ចសន្យាជួលក្លាយជា
> វិក្កយបត្រ វិក្កយបត្រក្លាយជាការទូទាត់ និងការទូទាត់បង្ហាញនៅលើ P&L — អ្នក
> យល់ប្រព័ន្ធនេះហើយ។ ដំណើរនោះត្រូវបានគូរនៅ **ផ្នែក 1, §1.4** និង
> បង្រៀនជំហានបន្តិចម្ដងនៅ **ផ្នែក 13 (Golden Path)**។
