# ផ្នែក ១២ — វាក្យសពទ

និយមន័យសាមញ្ញ នៃពាក្យដែលប្រើ នៅក្នុង RentManager។ កូដម៉ូឌូល ក្នុងវង់ក្រចក។

| ពាក្យ | អត្ថនយភាសាសាមញ្ញ |
|---|---|
| **Property (អចលនទ្រព្យ)** | ទីតាំង/គម្រោងជួល — កម្រិតខាងលើ នៃដើមឥត្ថិភាពសារពត៌មាន។ |
| **Building (អគារ)** | អគារ ក្នុងអចលនទ្រព្យមួយ ដែលម្ចាស់ម្នាក់ ជាម្ចាស់។ |
| **Floor (ជាន់)** | ជាន់ ក្នុងអគារមួយ។ |
| **Room / Bed (បន្ទប់ / គ្រែ)** | ឯកតាដែលអាចជួលបាន។ គ្រែ ជួលបន្ទប់ ដាច់ដោយឡែក នៅក្នុង co-living។ |
| **Room status (ស្ថានភាពបន្ទប់)** | vacant · reserved · occupied · cleaning · maintenance (ម៉ាស៊ីនស្ថានភាព)។ |
| **Owner (landlord) (ម្ចាស់ផ្ទះ)** | បុគ្គល/ក្រុមហ៊ុន ដែលជាម្ចាស់អគារ និងទទួលបានរបាយការណ៍ម្ចាស់។ |
| **Owner contract [M05] (កិច្ចសន្យាម្ចាស់)** | ព្រមព្រៀងគ្រប់គ្រង៖ FIXED_RENT (ថ្លៃជួលម៉ាស្ទ៊រ) ឬ REVENUE_SHARE (ភាគរយ + ហាម)។ |
| **Member / Tenant (សមាជិក / អ្នកជួល)** | អ្នកស្នាក់/អ្នកកាន់កាប់។ វដ្តជីវិត prospect→verified→active→notice→moved_out។ |
| **KYC** | ឯកសារអត្តសញ្ញាណ ដែលសមាជិកត្រូវឡូត មុនពេល verified (ប័ស្ប៊ា/ID ដើម)។ |
| **Party** | កំណត់រឿងរួម សម្រាប់បុគ្គល ឬក្រុមហ៊ុណណាមួយ (សមាជិក ម្ចាស់ អ្នកផគត់ផ្គង់ អ្នកទំនាក់ទំនង)។ |
| **Lease [M05] (កិច្ចសន្យាជួល)** | ព្រមព្រៀងស្នាក់ របស់សមាជិក សម្រាប់បន្ទប់/គ្រែ (draft→active→notice→terminated/completed)។ |
| **Rent plan / Rent engine [M06]** | ក្បួនគណនាប្រាក់ (ចំនួន ថ្ងៃវដ្ត ការប្រកាន់ ប្រាក់សោភ័ណ ពន្ធ ការកាត់) ដែលបង្កើតក្បួនវិក្កយបត្រ។ |
| **Cycle day (ថ្ងៃវដ្ត)** | ថ្ងៃខែ ដែលថ្លៃជួលត្រូវបានគណនា (កំណត់ 1–28)។ |
| **Proration (ការប្រកាន់)** | គណនាប្រាក់ តែសម្រាប់ថ្ងៃដែលបានស្នាក់ ក្នុងខែផ្នែក (ឧ. 17/31)។ មូលដ្ឋាន = calendar ឬ 30-day។ |
| **Invoice [M07] (វិក្កយបត្រ)** | វិក្កយបត្រខែ របស់សមាជិក។ ស្ថានភាព draft→issued→partial_paid→paid→overdue (ឬ void)។ លេខគ្មានរន្ធ {PROP}-{YEAR}-{SEQ}។ |
| **Credit note** | របៀបត្រឹមត្រូវ ដើម្បីកាត់បន្ថយ វិក្កយបត្រដែលបាន issue (immutable)។ បញ្ចប់ដរត្ានៅសូន្យ។ |
| **Void** | បោះបង់វិក្កយបត្រ — **Super Admin តែប៉ុណ្ណោះ** ត្រូវការមូលហេតុ។ លេខ មិនដែលប្រើឡើងវិញ។ |
| **Dunning (ការជ្រើស)** | ជួរការជ្រើស សម្រាប់វិក្កយបត្រផុតកាល (+3/+7/+14 ថ្ងៃ)។ |
| **Late fee (ប្រាក់សោភ័ណ)** | ថ្លៃ បន្ទាប់ពីរយៈពេលរការ។ flat ឬ % (ជាមួយកម្រិត)។ មិនដែលលើសចំនួនដែលត្រូវបង់។ |
| **Payment [M09] (ការទូទាត់)** | ប្រាក់ដែលទទួល (cash/bank_transfer/qr/card/cheque)។ pending→confirmed→refunded/failed។ |
| **Receipt (ប័ណ្ណទូទាត់)** | ភស្តុតាងការទូទាត់ ដែលមានលេខ (`RCP-…`)  PDF រក្សាទុកដ្រតរា។ |
| **Allocation (ការបែងចែក)** | ការអនុវត្ត ការទូទាត់ ទៅវិក្កយបត្រ ពីចាស់ទៅថ្មី។ សរុប ស្មើការទូទាត់។ |
| **Member credit** | ប្រាក់ដែលសមាជិកបង់លើស រក្សាទុក នៅក្នុងគណនី (អាចត្រឡប់) — មិនមែនជាចំណូល។ |
| **Refund (ការត្រឡប់)** | ការត្រឡប់ប្រាក់។ ត្ូវការការអនុម័ត Accountant+។ រំលំចំណុចបញ្ជី។ |
| **QR payment [M13] (ការទូទាត់ QR)** | ការបង់តាម QR។ QR សមាជិក បើកទំព័រ `/pay` សាធារណ (គ្មានការចូល តែ exact-due)។ |
| **Deposit [M10] (ប្រាក់កក់)** | ប្រាក់កក់សន្សំ ដែលរក្សាទុក សម្រាប់កិច្ចសន្យាជួលមួយ។ ត្រូវបានគណនាប្រាក់ ជាតម្រូវ។ រក្សាទុក នៅក្នុងប្រាក់រំលង (មិនមែនជាចំណូល)។ |
| **Deposit deduction** | ការរក្សាទុក ផ្នែកនៃប្រាក់កក់ នៅពេលចាកចេញ (ខូចខាត/សុប្បកម្ម/ថ្លៃជួលមិនទាន់បង់) — ត្រូវការភស្តុតាង + មូលហេតុ។ |
| **Utility [M11] (ទឹកអគ្គិសនី)** | ថ្លៃតាមម៉ែត្រ (អគ្គិសនី/ទឹក/ឧស្័ន) = ការប្រើ × តារីហ្វបន្ទាត់។ ត្រូវបានគណនាប្រាក់ នៅវិក្កយបត្របន្ទាប់។ |
| **Service [M12] (សេវា)** | កម្មសេវា (WiFi កន្លែងជម្រករថយន្ត គណនី WiFi ប្រអប់សម្ុប)។ Fixed ខែ ឬ per-use។ |
| **Ledger [M08] (បញ្ជី)** | សៀវភៅ double-entry ដែលមិនអាចផ្លាស់ប្ដូរបាន នៃព្រឹតតិការណ៍ប្ាក់ទាំងអស់ (append-only)។ |
| **Journal (ចង្វាក់)** | បញ្ជីលំដាប់ពេលវេលា នៃចំណុចបញ្ជី។ |
| **Trial balance** | ការពិនិត្យ ថាសរុប debits = សរុប credits (គួរស្មើសូន្យ)។ |
| **Debit / Credit** | ទ្រង់ទ្រាយទាំងពីរ នៃចំណុច foreach (Σ debits = Σ credits ជានិច្ច)។ |
| **Account (គណនី)** | ធុងដែលតាមដាន៖ Cash (1100) Bank (1200) Rent Receivable (1300) Deposit Liability (2100) Owner Payable (2200) Tax Payable (2300) Owner Distributions (3900) ចំណូល 4000–4900 ចំណាយ 5000–5100។ |
| **Receivable (ប្រាក់រង់ចាំ)** | ប្រាក់ដែលសមាជិកត្រូវបង់ (ទ្រព្យ) រហូតដល់បង់។ |
| **Revenue / Income (ចំណូល)** | ប្រាក់ដែលបានរក (ថ្លៃជួល សេវា ទឹកអគ្គិសនី ប្រាក់សោភ័ណ ផ្សេង)។ |
| **Expense [M20] (ចំណាយ)** | ប្រាក់ចាយ ក្នុងប្រតិបត្តិការ។ ចំណាយ ក្រោម $500 auto-approve។ លើស ត្រូវការការអនុម័ត។ |
| **Asset (ទ្រព្យ)** | អ្វីដែលអាជីវកម្មរកសាទុក (ប្រាក់សាច់ ធាគារ ប្រាក់រង់ចាំ)។ |
| **Liability (ប្រាក់រំលង)** | អ្វីដែលអាជីវកម្មតរូវបង់ (ប្រាក់កក់ដែលរក្សាទុក ប្រាក់ដែលត្រូវបង់ម្ចាស់ ពន្ធ)។ |
| **Equity (សមាជិកភាព)** | ការចុះរបស់ម្ចាស់ / ការបែងចែកម្ចាស់ (គណនី 3900)។ |
| **Reversal (ការរំលំ)** | ចំណុចកែតម្រូវ ដែលលុបចំណុចដែលបានចុះ (ដើមនៅសល់)។ |
| **Profit & Loss (P&L) [M20/M26]** | ចំណូល − ចំណាយ (និងការបង់ម្ចាស់) = ប្រាក់បៀត/បាត់សុទ្ធ សម្រាប់រយៈពេលមួយ។ |
| **Owner statement [M24] (របាយការណ៍ម្ាស់)** | របាយការណ៍បង់ប្រាក់ ប្រចាំខែ ក្នុងមួយម្ចាស់៖ បានប្រមូល × ភាគ (ឬថ្លៃជួលថេរ) − ហាម − ចំណាយ។ draft→approved→paid។ |
| **Owner payable (2200)** | ប្រាក់ដែលត្រូវបង់ម្ចាស់ (ប្រាក់រំលង) បានសម្អាត នៅពេលដែលបង់។ |
| **POS [M14]** | តារាសាធារណៈ point-of-sale៖ វដ្ដកាស៊ែរ ប្រាក់ float ការលក់ charge-to-room។ |
| **Charge to room** | ការលក់ POS ដែលត្រូវបានគណនាប្រាក់ ទៅអ្នកស្នាក់ ជាវិក្កយបត្រ one-time។ |
| **Stock [M15] (ស្តុក)** | ស្តុកទំនិញ។ ផ្លាស់ប្ដូរ តាមរយៈចលនា តែ (purchase/sale/consumption/adjustment/transfer)។ |
| **Purchase order (PO) [M29] (លិខិតបញ្ជាទិញ)** | ការបញ្ជាទិញអ្នកផ្គត់ផ្គង់ ដែលបានគ្រោង។ Placement ជា bookkeeping។ Receiving បន្ថែមស្តុក។ |
| **Stocktake (ការរាប់ស្តុក)** | ការរាប់ស្តុកពិត។ variance ចុះ adjustment មួយ។ |
| **Moving-average cost** | វិធីសាស្ត្រការវាយតម្លៃស្តុក (ថ្លៃដើមក្នុងមួយឯកតា មធ្យម ការទិញថ្មី)។ |
| **Room move [M16] (ការផ្លាស់បន្ទប់)** | ការផ្លាស់អ្នកស្នាក់ រវាងបន្ទប់។ បង្កើតវិក្កយបត្រ adjustment សុទ្ធ មួយ។ បន្ទប់ទាំងពីរ ផ្លាស់ប្ដូរស្ថានភាព។ |
| **Inspection [M18] (ការត្រួតពិនិត្យ)** | បញ្ជីផទៀងផទាត់ស្ានភាព ចូល/ចាកចេញ/ប្រចាំ។ ការចាកចេញ ចាំបាច់ ដើម្បីបញ្ចប់កិច្ចសនយាជួល។ |
| **Finding (ការរកឃើញ)** | ធាតុត្រួតពិនិត្យ ដែលបានរង។ អាចបើកសំបុត្រជួសជុល ឬអនុសាសការកាត់ប្រាក់កក់។ |
| **Maintenance ticket [M19] (សំបុត្រជួសជុល)** | ការងារជួសជុល៖ open→assigned→in_progress→resolved→verified/closed។ SLA តាមអាទិភាព។ |
| **SLA** | គោលដៅពេលវេលា service-level (urgent ៤ ម៉ោង … low ១៦៨ ម៉ោង)។ ការបំផ្លាញ ត្រូវបានស្កេនប្រចាំថ្ងៃ។ |
| **Complaint [M22] (ការតវ៉ា)** | ការរិវល់របស់សមាជិក៖ new→acknowledged→in_progress→resolved→closed។ អាចប្ដូរទៅសំបុត្រ។ វាយតម្លៃ 1–5។ |
| **Attendance [M23] (ការវត្តមាន)** | ការចុះ/ឡើងកម្មករ (kiosk PIN ឬ mobile geofence)។ ជម្រើស។ CSV payroll ចេញ។ |
| **Short stays [M32] (ការស្នាក់ខលី)** | ការកក់ hourly/daily បែបសណ្ឋាគារ (`STY-…`) តាមរយៈ rent modules & rate rules។ |
| **Tenant portal [M25] (ខ្លោងទ្វារអនកជួល)** | Web app self-service សមាជិក នៅ `/portal` (ការចូល OTP តែទិន្នន័យផទាល់ខ្លួន)។ |
| **Owner portal (ខ្លោងទ្វារម្ចាស់)** | ទិដ្ឋភាពអានតែ សម្រាប់ម្ចាស់ផ្ទះ នូវអគារ/របាយការណ៍/ឯកសាររបស់ពួកគេ។ |
| **Telegram bot [M21]** | ការរួមបញ្ចូល chat សម្រាប់ការជូនដំណឹង និង `/status /dues /pay`។ ភ្ជាប់ ជាមួយកូដមួយដង។ |
| **Reports [M26] (របាយការណ៍)** | ការវិភាគ ១៣ ដែលមានបញ្ជី/query គាំទ្រ ជាមួយការនាំចេញ CSV/PDF។ |
| **Arrears (លំណូល)** | ប្រាក់សរុបដែលនៅតែត្រូវបង់ លើវិក្កយបត្របើក។ |
| **Occupancy %** | បន្ទប់ដែលមានអ្នកស្នាក់  បន្ទប់សរុប។ |
| **Cash position (ស្ថានភាពប្រាក់សាច់)** | តម្លៃបញ្ជី Cash (1100) + Bank (1200) (KPI dashboard)។ |
| **Audit log [M01/M27]** | កំណត់រឿង ដែលមើលឃើញការប៉ះប៉ាល់ append-only នៃការផ្លាស់ប្ដូរ foreach (actor ពេលវេលា មុន/បន្ទាប់ IP)។ |
| **Role (តួនាទី)** | ក្រុមសិទ្ធិ ដែលមានឈ្មោះ (Super Admin Admin Property Manager Accountant Staff Owner Member ឬផ្ទាល់ខ្លួន)។ |
| **Permission (សិទ្ធិ)** | ម៉ូឌូល × អំពើ × ជួរ (ឧ. `M09:approve` នៅជួរ PROPERTY)។ |
| **Action (អំពើ)** | create · read · update · delete · approve · void · refund · export · config។ |
| **Scope (ជួរ)** | GLOBAL (អចលនទ្រព្យទាំងអស់) · PROPERTY (អចលនទ្រព្យដែលបានចែកចាយ) · OWN (តែកំណត់រឿងផ្ទាល់ខ្លួន)។ |
| **RBDC** | Role-Based Dynamic Access Control — ប្រព័ន្ធសិទ្ធិ ដែលអនុវត្ត នៅរាល់ការហៅ API។ |
| **Feature flag** | ប៉ុកបិទ/បើកកម្រិតអង្គភាព សម្រាប់ម៉ូឌូល (Settings → Features)។ |
| **2FA / TOTP [M27]** | ការស្គាល់អត្តសញ្ញាណពីរជាន់ តាមរយៈ authenticator app។ ចាំបាច់សម្រាប់ Admin+។ |
| **Session (សន្និសីន)** | បរិស្ថាន browser ដែលបានចូល។ អាចកាត់បន្ថយបាន។ ផុតកាល បន្ទាប់ពីចំនួនថ្ងៃជាក់លាក់។ |
| **Feature/module code (Mxx)** | កូដសិទ្ធិផ្ទៃក្នុង (M01…M33) ដែលបង្ហាញ នៅអេក្រង់តួនាទី និងប្រើដោយ `can()`។ |
| **Minor units** | ប្រាក់រក្សាទុក ជាចំនួនដឺក្រី cent ដើម្បីជៀសវាងកំហុសការងើប (រូបិយប័ណ្ណតែមួយរបស់អង្គភាព)។ |
| **Forward-only** | ការផ្លាស់ប្ដូរការកំណត់ អនុវត្ត ទៅប្រតិបត្តិការអនាគត តែប៉ុណ្ណោះ។ ប្រវតតិដែលបានចុះ មិនដែលដីវិញ។ |
| **Idempotent** | ការដំណើរការការងារពីរដង ផ្ដល់លទ្ធផលដូចគ្នា (គ្មានវិក្កយបត្រ/ការទូទាត់ចម្លង)។ |
