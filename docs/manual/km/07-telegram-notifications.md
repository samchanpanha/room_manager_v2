## 7.1 Telegram bot (M21) — វាធ្វើអ្វី

- ផ្ញើ**ការជូនដំណឹងព្រឹត្តិការណ៍** ទៅអ្នកប្រើដែលបានភ្ជាប់ (សមាជិក កម្មករ ម្ចាស់)។
- ឆ្លើយតបកូតាប់ **commands** មួយចំនួន នៅក្នុង chat (សមាជិកមើលតែទិន្ននយ**ផ្ទាល់ខ្លួន**)។
- អាចត្រឡប់ **QR ទូទាត់** ដើម្បី្យសមាជិកបង់ ពីក្នុង chat។

### ការជូនដំណឹងដែលមាន (ព្រឹត្តិការណ៍ → template)
| ព្រឹត្តិការណ៍ | អ្នកទទួល | នៅពេលណាដែលវាចុះផ្ដើម |
|---|---|---|
| `invoice.issued` | សមាជិក | វិក្កយបត្រត្រូវបាន issue |
| `payment.confirmed` | សមាជិក | ការទូទាត់ត្រូវបានបញ្ជាក់ (សារប័ណ្) |
| `invoice.dunning_reminder` | សមាជិក | ដំណាក់ទំនាក់ dunning បានកំណត់ (+3/+7/+14) |
| `rent.reminder` | សមាជិក | ថ្លៃជួលជិតដល់ (ពីការងារ rent-alerts) |
| `rent.overdue` | សមាជិក | ថ្លៃជួលផុតកំណត់ |
| `ticket.transitioned` | សមាជិក | សំបុត្រជួសជុលផ្លាស់ប្ដូរស្ថានភាព |
| `complaint.transitioned` | សមាជិក | ការតវ៉ាផ្លាស់ប្ដូរស្ថានភាព |
| `statement.approved` | ម្ចាស់ | របាយការណ៍ម្ចាស់ត្រូវបានអនុម័ត/រួចរាល់ |
| `stock.low` | កម្មករ/admin | ធាតុធ្លាក់ក្រោមអង្គុយស្តុកទាប |
| *(occupancy digest)* | គេហទំព័រកម្មករ | សង្ខេប occupancy ប្រចាំថ្ងៃ (តាមការងារ dispatch) |

អ្នកប្រើ foreach មាន**ការកំណត់ toggle ក្នុងមួយអ្នកប្រើ** (បើក/បិទប្រភេទការជូនដំណឹង foreach)។

### Bot commands
| Command | អ្នក | វាត្រឡើងអ្វី |
|---|---|---|
| `/start` | គ្រប់គេ | អត្ថបទស្វាគមន៍/ជំនួយ (អាចកំណត់បាន) |
| `/link <code>` | អ្នកប្រើ | ភ្ជាប់គណនី Telegram ទៅអ្នកប្រើ RentManager (កូដមួយដង) |
| `/status` | សមាជិក | ស្ថានភាពកិច្ចសន្យាជួល/បន្ទប់បច្ចុប្បន្ (ទិន្ននយផ្ទាល់ខ្លួន) |
| `/dues` | សមាជិក | តម្លៃដែលនៅសល់ (តែទិន្ននយផ្ទាល់ខ្លួន) |
| `/pay` | សមាជិក | QR ទូទាត់ សម្រាប់អ្វីដែលត្រូវបង់ (តាម M13) |
| `/help` | គ្រប់គេ | បញ្ជី commands |

សុវត្ថិភាព៖ bot ប្រើ**signed webhook** (ការធ្វើជំនួស ត្រូវបានបដិសេធ)៖
commands សមាជិក ត្រូវបានពិនិត្យ RBDC ហើយតែងតែត្រឡើងតែទិន្ននយ**សមាជិកនោះ**។

## 7.2 ការភ្ជាប់ Telegram របស់អ្នក (linking)

ការភ្ជាប់ ប្រើ**កូដមួយដង** (bot មិនឃើញពាក្យសមងាត់របស់អ្នកទេ)។

### ពីខាង admin/owner
1. បើក **Comms → Telegram Bot** (ឬ **My Account**)។
2. ជ្រើស**ភ្ជាប់** គណនីរបស់អ្នក — ប្រព័ន្ធបង្ហាញ**link code** មួយដង។
3. នៅក្នុង Telegram បើក bot ហើយផ្ញើ `/link <code>`។
4. Bot ភ្ជាប់ `telegram_id` របស់អ្នក (បានពិនិត្យសិទ្ធិ) ហើយបញ្ជាក់។
5. កំណត់**toggles ការជូនដំណឹង**របស់អ្នក (សារអ្វីដែលអ្នកចង់បាន)។

### ពីខ្លោងទ្វារអនកជួល (សមាជិក)
1. សមាជិកបើក bot ហើយផ្ញើ `/link <code>` ប្រើកូដដែលបង្ហាញ នៅក្នុង portal របស់ពួកគេ។
   - ការ self-linking សមាជិក អាចបើក/បិទ ដោយអង្គភាព តាម
     **Settings → Telegram → allowMemberLinking**។
2. នៅពេលភ្ជាប់ ពួកគេទទួលប័ណ្ណ/ការជ្រើស និងអាចប្រើ `/status`, `/dues`, `/pay`។

### ដកការភ្ជាប់
ប្រើ**unlink** នៅអេក្រង់ Telegram (ឬ `/link` ជាមួយគណនីថ្មី)។ ការដកភ្ជាប់
ឈប់សារ សម្រាប់ chat នោះ។

> មានដំណើរការ **admin-link** ផងដែរ (`/api/telegram/admin-link`) សម្រាប់ការ
> រៀបចំកម្មករ និងការត្រួតពិនិត្យ **link-state** ដែល UI ប្រើ។

## 7.3 ការផ្ញើឯកសារ / ពត៌មាន តាម Telegram

- **ឯកសារដែលបានបង្កើត ត្រូវបានផ្ដល់ជាសារ Telegram** កនុងករណីដែលឯកសារ ភ្ជាប់
  ទៅព្រឹតតិការណ៍មួយ — ជាពិសេស**ប័ណ្ទូទាត់** នៅ `payment.confirmed` និង
  **របាយការណ៍ម្ចាស់** នៅពេលវាត្រូវបានអនុម័ត (`statement.approved`)។
  វិក្កយបត្រ PDF ត្រូវបានរក្សាទុក នៅក្នុងវគ្គកំណត់ឯកសារ ហើយសមាជិកក៏អាចមើលវា នៅក្នុង
  portal ដែរ។
- **token** bot ត្រូវបានរក្សាទុកជា**secret ដែលបានស្គរ** (AES-256-GCM, masked នៅក្នុង UI)។
  បង្វិលវា នៅ **Settings → Providers/Secrets**។
- នៅក្នុងបរព័ន្ំនើប/demo អ្នកផ្ញើ bot ត្រូវបាន **mocked** — សារត្រូវបានកត់ត្រា នៅក្នុង
  **outbox** (បង្ហាញនៅអេក្រង់ admin Telegram: ស្ថានភាព/ខ្លឹមសារ) ជំនួសការផ្ញើ
  ទៅ Telegram ពិត។ ការភ្ជាប់ពិត ប្រើ bot ពិត តាមរយៈ signed webhook។

> នៅអេក្រង់ admin Telegram អ្នកអាចពិនិត្យ chat ដែលបានភ្ជាប់ (Principal / Linked)
> បិទការជូនដំណឹង តាមព្រឹត្តិការណ៍ ហើយមើល **outbox** (ស្ថានភាព និងខ្លឹមសារសារ) —
> មានប្រយោជន៍ ដើម្បីបញ្ជាក់អ្វីដែល*នឹង*ត្រូវបានផ្ញើ។

## 7.4 ការជូនដំណឹង in-app (មិនត្រូវការការរៀបចំ)

ទោះបីគ្មាន Telegram ក៏ដោយ ប្រព័ន្ធសូរព័ត៌មានការជ្រើស ក្នុង App៖

| ទីតាំង | អ្វី |
|---|---|
| **Dashboard → Rent dues (M33)** | វិក្កយបត្រ ដែលដល់ក្នុងបង្អួច "ថ្ងៃមុន" និងវិក្កយបត្រផុតកំណត់ |
| **សញ្ញា dues សមាជិក** | សញ្ញាប្រភេទ "$265.00 due" នៅលើសមាជិក/វិក្កយបត្រ |
| **សញ្ញាហេតុកាលឯកសារ** | KYC/ឯកសារ កំពុងផុតកាល (ការជ្រើស ៣០/៧ ថ្ងៃ) |
| **Reports → Overdue & not paid** | បញ្ជីការងារ ថ្លៃជួលផុតកំណត់ |
| **ស្តុកទាប** | ធាតុ ក្រោមអង្គុយ (ក៏ជាព្រឹត្តិការណ៍ Telegram `stock.low` ផង) |
| **SLA / សញ្ញាបំផ្លាញ** | សំបុត្រ/ការតវ៉ាផុតកាល (KPIs ជួសជុល/ការតវ៉ា) |

## 7.5 ការងារផ្ទៃខាងក្រោយ ដែលបង្កើតការជូនដំណឹង

ការងារទម្រង់ cron ទាំងនេះ (បង្ហាញ/ចាប់ផ្ដើម តាមសិទ្ធិ) ប្ដូរស្ថានភាព ទៅជាសារ៖

| ការងារ | ធ្វើ | សិទ្ធិ |
|---|---|---|
| **billing-daily** | ប្រាក់សោភ័ណ បន្ទាប់ពីរការ; សម្គាល់ overdue; ការជ្រើស dunning | M06:update |
| **rent-alerts** | ចេញព្រឹតតិការណ៍ ថ្លៃជួលជិតដល់/ផុតកាល (M33) | M33:update (Admin/PM) |
| **telegram-dispatch** | ទាញព្រឹត្តិការណ៍ → សារ Telegram; សង្ខេប occupancy ប្រចាំថ្ងៃ | M21:update (Admin+) |
| **sla-sweep** | សម្គាល់ការបំផ្លាញ SLA នៅលើសំបុត្រ & ការតវ៉ា (ឡើងកម្រិត) | M19:update (staff+) |
| **attendance-sweep** | សម្គាល់ការភ្លេចចុះ-ឡើង | M23:update |
| **invoice-generation** | បង្កើតវិក្កយបត្ររយៈពេល | M07:create |
| **statement-generation** | បង្កើតរបាយការណ៍ម្ចាស់ | GLOBAL M24:update |

### ការប្ដូរពាក្យសារ
**Settings → Templates** អនុញ្ញាតឱ្យ admin ជំនួស template Telegram សម្រាប់
ព្រឹត្តិការណ៍ ៖ `invoice.issued`, `payment.confirmed`, `invoice.dunning_reminder`,
`rent.reminder`, `rent.overdue`។ Templates គាំទ្រ placeholders ដូចជា `{total}`,
`{due}`, `{receipt}`, `{code}`។ ព្រឹតតិការណ៍ ដែលគ្មានការជំនួស ប្រើ default ដែលស្ថិតក្នុង។
