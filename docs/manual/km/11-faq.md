# ផ្នែក ១១ — សំណួរដែលសួរញឹកញាប់ (FAQ)

សរសេរជាភាសារបស់ប្រចាំថ្ងៃ។ សំណួរប្រើពហុផ្នែក៖ "**ស** / **ច**"។

**ការចូល**
- **ស៖ តើខ្ញុំចូលយ៉ាងម៉េច?** បញ្ចូល email ការងារ និងពាក្យសម្ងាត់ នៅទំព័រចូល។ គណនី Admin ក៏បញ្ចូលកូដ 2FA ផង។ ពាក្យសមងាត់ថ្មី ដែល admin កំណត់ ត្រូវផ្លាស់ប្ដូរ នៅពេលចូលដំបូង។
- **ស៖ ខ្ញុំភ្លេចពាក្យសម្ងាត់ — មាន email កំណត់ឡើងវិញឬទេ?** គ្មាន នៅក្នុងប្រព័ន្ធជាបច្ចុបបន្ន (គ្មានបណ្ដាញ email)។ សួរអ្នកគ្រប់គ្រង ្យកំណត់ពាក្យសមងាត់បណ្ដោះអាសន្ន។ អ្នកនឹងផ្លាស់ប្ដូរវា នៅពេលចូលម្ដងបន្ទាប់។
- **ស៖ ហេតុអ្វីខ្ញុំមើលមិនឃើញាតុម៉ឺនុយ?** តួនាទីរបស់អ្នក គ្មានសិទ្ធិសម្រាប់វា (ឬ feature flag បិទ)។ នេះជាប៉ងប្រាស់ — សួរ admin បើអ្នកត្រូវការ។
- **ស៖ ខ្ញុំតែងតែបាន "403 FORBIDDEN"។** អ្នកខ្វះសិទ្ធិម៉ូឌូល/អំពើ ឬមិនទាន់បានចែកចាយ ទៅអចលនទ្រព្នោះ។ ស្នើការចូល។ កុំព្យាយាម workarounds។
- **ស៖ សមាជិកចូលទៅ portal អ្នកជួល យ៉ាងម៉េច?** ដោយពាក្យសមងាត់មួយដង (OTP) ដែលផ្ញើទៅ email/ទូរស័ព្ទរបស់ពួកគេ។ កូដប្រើម្ដង និងបិទ បន្ទាប់ពី ៥ ដង។

**អចលនទ្រព្យ សមាជិក កិច្ចសនយាជួល**
- **ស៖ តើខ្ញុំបង្កើតការជួល/កិច្ចសន្យាជួល យ៉ាងម៉េច?** ដំបូង បញ្ជាក់ថា អចលនទ្រព្យ→អគារ→ជាន់→បន្ទប់ មាន ហើយសមាជិក បាន KYC-verified។ បន្ទាប់មក **Leases → New** ជ្រើសសមាជិក + បន្ទប់ កំណត់ថ្លៃជួល/ចាប់ផ្ដើម/ប្រាក់កក់/សេវា រក្សាទុក draft បន្ទាប់មក **Activate** (ផ្នែក 3.6)។
- **ស៖ បន្ទប់អាចមានអ្នកជួលពីរឬទេ?** តែរហូតដល់ទំហំគ្រែរបស់វា។ មាន**កិច្ចសន្យាជួលសកម្មមួយ ក្នុងមួយគ្រែ**។ ប្រព័ន្ធដប់សេចក្ដីរំលោភប្រាស។
- **ស៖ តើខ្ញុំផ្លាស់ប្ដូរថ្លៃជួលខែ យ៉ាងម៉េច?** អ្នកមិនកែវិក្កយបត្រដែលបានចុះទេ។ លក្ខខណ្ឌថ្ៃជួល ត្រូវបាន snapshotted នៅលើកិច្ចសន្យាជួល។ ការផ្លាស់ប្ដូរអនាគត ប្រើការចុះវិញ/ការផ្លាស់បន្ទប់/លក្ខខណឌកិចចសន្យាជួលថ្មី។ ការផ្លាស់ប្ដូរការកំណត់ អនុវត្ត**ទៅមុខតែ**។
- **ស៖ ពណ៌/ស្ថានភាពបន្ទប់មានន័យអ្វី?** vacant (ទទេ) reserved (draft lease) occupied (active lease) cleaning (បន្ទាប់ពីចាកចេញ) maintenance (ត្រូវការការជួសជុល)។
- **ស៖ តើខ្ញុំលុបចេញ/បញ្ចប់កិច្ចសន្យា យ៉ាងម៉េច?** ផ្ដល់ដំណឹង សម្អាតលំណូល (ឬការសរសេរចេញដែលបានអនុម័ត) បញ្ចប់ការត្រួតពិនិត្យចាកចេញ បន្ទាប់មក terminate/complete។ បន្ទប់ទៅ cleaning ហើយប្រាក់កក់ ត្រូវបានបញ្ចប់។
- **ស៖ តើខ្ញុំដាក់អ្នកជួលក្នុង blacklist យ៉ាងម៉េច?** ពីព័ត៌មានសមាជិក ជាមួយមូលហេតុចាំបាច់។ វាឃាំងការផ្លាស់ប្ដូរស្ថានភាព និងកិច្ចសនយាជួលថមី។ ការដក blacklist ក៏ត្រូវបានត្រាតរួតពិនិតយដែរ។

**ការគណនាប្រាក់ & ប្រាក់**
- **ស៖ វិក្កយបត្រខែត្រូវបានធ្វើឡើង យ៉ាងម៉េច?** អ្នកមិនវាយវាទេ។ ដំណើរការ **ការបង្កើតវិក្កយបត្រ** (ឬការងារកំណត់)៖ ថលៃជួល + សេវា + ទឹកអគ្គិសនី + មួយដង − ការកាត់ + ពន្ធ។ វាជា idempotent និងលេខគ្មានរន្ធ។
- **ស៖ ខ្ញុំអាចបន្ថែមសេវាច្រើនឬទេ?** បាន — WiFi ជម្រករថយន្ត បរអប់សម្ុប ដើម។ សេវា fixed ខែ ត្រូវបានគណនាប្រាក់ រាល់ខែ (ប្រកាន់ បើចាប់ផ្ដើម/ឈប់ ចំកណ្ដាលខែ)។ ការប្រើ per-use ក្លាយជាក្បួន one-time។
- **ស៖ តើខ្ញុំកត់ត្រាការទូទាត់ផ្នែក យ៉ាងម៉េច?** គ្រាន់តែបញ្ចូលចំនួនដែលទទួល។ វាត្រូវបានបែងចែក ពីចាស់ទៅថ្មី និងវិក្កយបត្រក្លាយជា **partial_paid**។ ភាគផ្សេង នៅតែត្រូវបង់។
- **ស៖ ហេតុអ្វីអ្នកជួល នៅបង្ហាញតម្លៃដែលនៅសល់ បន្ទាប់ពីបង់?** ការទូទាត់អាចជា **pending** (QR មិនទាន់បានបញ្ជាក់) ត្រូវបានកត់ត្រា ប្រឆាំងសមាជិកខុស ឬវាជាផ្នែក។ ពិនិត្យស្ានភាពការទូទាត់ និងការបែងចែក។
- **ស៖ អ្វីដែលកើតឡើង បើអ្នកជួលបង់លើស?** ប្រាក់លើស ត្រូវបានរក្សាទុកជា **member credit** (មិនមែនជាចំណូល) អាចត្រឡប់ ដោយគណនី។
- **ស៖ ខញុំអាចផលាស់ប្ដូរ ឬលុប ការទូទាត់/វិក្កយបត្រចាស់ ឬទេ?** គ្មានការលុប។ កែវិក្កយបត្រ ដោយ **credit note** (ឬ Super-Admin void ជាមួយមូលហេតុ)។ រំលំការទូទាត់ ដោយ **refund** (ការអនុម័តគណនី)។
- **ស៖ ប្រាក់សោភ័ណ និងការជ្រើស ដំណើរការយ៉ាងម៉េច?** បន្ទាប់ពីរយៈពេលរការ (លំនាំដើម ៣ ថ្ងៃ) ការងារប្រចាំថ្ងៃ បន្ថែមប្រាក់សោភ័ណ និងសម្គាល់ overdue។ ការជ្រើស dunning ចេញ នៅ +3/+7/+14 ថ្ងៃ។
- **ស៖ ប្រាក់កក់ ជាចំណូលរបស់ខ្ញុញឬទេ?** ទេ — វាជាប្រាក់ដែលរក្សាទុក (ប្រាក់រំលង)។ វាត្រូវបានត្រឡប់ កាត់ (ជាមួយភស្តុតាង) នៅពេលចាកចេញ។
- **ស៖ តើខ្ញុំអានបញ្ជី យ៉ាងម៉េច?** បើក **Finance → Ledger**៖ journal (ចំណុចតាមលំដាប់ពេលវេលា) និង trial balance។ ចំណុច foreach តុល្យ debits = credits (ផ្នែក 5)។
- **ស៖ តើខ្ញុំមើលប្រាក់បៀត យ៉ាងម៉េច?** របាយការណ៍ **Profit & Loss** (ឬ Expenses & P&L)៖ ចំណូល − ចំណាយ − ការបង់ម្ចាស់ = សុទ្ធ។

**របាយការណ៍**
- **ស៖ អនកណាអាចមើលរបាយការណ៍ហិរញ្ញវត្ថុ?** របាយការណ៍ ត្រូវការ M26។ ហិរញ្ញវត្ថុ/admin មើលរបាយការណ៍ហិរញ្ញវត្ថុ។ អ្នកគ្រប់គ្រងអចលនទ្រពយ ទទួលបានរបាយការណ៍ប្រតិបត្តិការ សម្រាប់អចលនទ្រព្របស់ពួកគេ។ ម្ចាស់មើលប្រវត្តិ statement ផ្ទាល់ខ្លួន។
- **ស៖ មាន balance sheet ឬទេ?** គ្មានអេក្រង់ balance-sheet ដាច់ដោយឡែកទេ។ ប្រើ **Ledger → Trial balance** (ទ្រពយ 1100–1300 ប្រាក់រំលង 2100–2300 សមាជិកភាព 3900)។ មើលផ្នែក 5.6។
- **ស៖ តើខ្ញុំនាំចេញរបាយការណ៍ យ៉ាងម៉េច?** ប្រើប៊ូតុងនាំចេញ **CSV** ឬ **PDF** នៅលើរបាយការណ៍ foreach (ត្រាស់តាមហេតុ + អចលនទ្រព្)។

**ការជូនដំណឹង / Telegram**
- **ស៖ តើខ្ញុំភ្ជាប់ Telegram យ៉ាងម៉េច?** ទទួលកូដមួយដង នៅក្នុង app/portal ផ្ញើសារទៅ bot `/link <code>` បន្ទាប់មកបើក toggles ការជូនដំណឹងរបស់អ្នក (ផ្នែក 7.2)។
- **ស៖ ខ្ញុំនឹងទទួលបានប័ណ្ណ email ឬទេ?** គ្មាន នៅក្នុងការសាងសង់បច្ចុបបន្ន — សារដ្រតរា ទៅតាម Telegram។ badges in-app/dashboard ក៏បង្ហាញតម្លៃដែលត្រូវបង់ដែរ។
- **ស៖ សមាជិកអាចធ្វើអ្វី ក្នុង bot?** `/status` (កិច្ចសន្យាជួលរបស់ពួកគេ) `/dues` (តម្លៃ) `/pay` (ទទួល QR ទូទាត់) `/help`។ ពួកគេតែងតែមើលតែទិន្ននយផ្ទាល់ខ្លួន។

**Admin**
- **ស៖ តើខ្ញុំបន្ថែមអ្នកបរើថ្មី យ៉ាងម៉េច?** Admin → Users → New user (email + ពាក្យសម្ងាត់បណ្ដោះអាសន្ន បង្ខំផ្លាស់ប្ដូរ នៅពេលចូលដំបូង) បន្ទាប់មកចែកចាយតួនាទី និងអចលនទ្រព្យ (ផ្នែក 8.2)។
- **ស៖ តើខ្ញុំផ្លាស់ប្ដូរសិទ្ធិ យ៉ាងម៉េច?** Admin → Roles & Permissions → ដាក់ធាងក្រឡា ម៉ូឌូល × អំពើ × ជួរ។ ការផ្លាស់ប្ដូរ ត្រូវបានត្រាត្រួតពិនិត្យ។ កុំផ្ដល់ច្រើនជាងដែលត្រូវការ (ផ្នែក 8.3)។
- **ស៖ ខ្ញុំអាចលុបតួនាទី Super Admin ឬទេ?** ទេ — វាត្រូវបានប្រើបាន ដើម្បីានាថាគណនី full-access ជានិច្ចមាន។ តួនាទីដែលកំពុងប្រើ មិនអាចលុបបាន។
- **ស៖ តើខ្ញុំបិទម៉ូឌូល យ៉ាងម៉េច?** Settings → Features (feature flags)។ វាលាក់ម៉ូឌូល/រឹតការចូល ដោយមិនលុបទិន្ននយ។
- **ស៖ តើខ្ញុំកំណត់រូបិយប័ណ្ណ / ប្រាក់សោភ័ណ / dunning ណា?** Settings → Locale (រូបិយប័ណ្ណ) និង Settings → Billing / Late fee។ ទាំងនេះ អនុវត្តទៅមុខតែ។
